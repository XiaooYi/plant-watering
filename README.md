# plant-watering
<p>植物养护助手，适合家庭或植物爱好者使用。记录用户每次给花草浇水的频次和时间，解决用户记不清浇没浇水的痛点。包含以下功能：</p>
- 植物选择：提供6种常见植物选项（绿萝、多肉植物、仙人掌、吊兰、薄荷、虎皮兰），并标注了它们的类别（如观叶植物、多肉植物、香草植物）。
- 植物记录管理：显示最近的养护记录，包括植物名称、记录日期和时间，以及部分状态备注（如“状态良好”、“生长良好”）。
- 状态跟踪：支持用户记录和查看植物的养护历史，方便跟踪植物的生长状态。
